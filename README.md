# CMJGo

Web app for CMJ company. Powered by Vite, React, and Supabase.

## Setup

1. Copy `.env.example` to `.env`
2. Open your [Supabase project](https://supabase.com/dashboard/project/nuieqalrgphmfjrpqnjw/settings/api) and paste the **anon public** key into `VITE_SUPABASE_ANON_KEY`
3. Enable Email auth under Authentication → Providers
4. Create a user under Authentication → Users (or use Sign up later)
5. Run the app:

```bash
npm install
npm run dev
```
